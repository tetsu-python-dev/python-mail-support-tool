# Pythonによるメール送信業務支援ツール

## 概要

メール送信業務におけるテンプレート入力・送信予約を自動化するデスクトップアプリケーションです。

Playwrightによるブラウザ自動操作とTkinterによるGUIを組み合わせ、定型業務の効率化を目的として開発しました。

---

## 使用技術

- Python
- Playwright
- Tkinter
- JSON

---

## 主な機能

- メール送信ページを自動で開く
- テンプレートの自動入力
- 送信予約時間の設定
- テンプレート編集
- 予約時間編集
- 処理状況のリアルタイム表示

## 工夫した点

- GUIから各種設定を変更できるよう設計
- テンプレート・予約時間をJSONで管理し、コードを書き換えずに編集可能
- Playwrightを利用してブラウザ操作を自動化
- 業務担当者が扱いやすいシンプルな画面構成を意識
